# Detailed Tier

Net-new initiative, cross-team work, or ambiguous scope. Cues: "design doc", "RFC", "stakeholders", "epic", "multiple teams". Word budget: **~500-800 words** for the description. Keep the AC outcome-based even when the description is long.

## Sections to compose

In this order in the Description field, each read its guidance before drafting. Expand Background and Approach relative to the Standard tier:

1. Summary -- `.rulesync/docs/jira/ticket-sections/summary.md`
2. Background (expanded) -- `.rulesync/docs/jira/ticket-sections/background.md`
3. Approach (expanded) -- `.rulesync/docs/jira/ticket-sections/approach.md`
4. Out Of Scope -- `.rulesync/docs/jira/ticket-sections/out-of-scope.md`
5. Downstream Impact -- `.rulesync/docs/jira/ticket-sections/downstream-impact.md`
6. Future Work -- `.rulesync/docs/jira/ticket-sections/future-work.md`

Optionally add a **Risks / Trade-offs** section when the work carries meaningful uncertainty or contested decisions.

Plus Acceptance Criteria (dedicated JIRA field, not the description) -- `.rulesync/docs/jira/ticket-sections/acceptance-criteria.md`.

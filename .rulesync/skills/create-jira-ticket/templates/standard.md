# Standard Tier

Feature work the team broadly understands -- normal story-shaped work with no special qualifiers. Word budget: **~250-400 words** for the description.

## Sections to compose

In this order in the Description field, each read its guidance before drafting:

1. Summary -- `.rulesync/docs/jira/ticket-sections/summary.md`
2. Background -- `.rulesync/docs/jira/ticket-sections/background.md`
3. Approach -- `.rulesync/docs/jira/ticket-sections/approach.md`
4. Out Of Scope -- `.rulesync/docs/jira/ticket-sections/out-of-scope.md`
5. Downstream Impact -- `.rulesync/docs/jira/ticket-sections/downstream-impact.md`
6. Future Work -- `.rulesync/docs/jira/ticket-sections/future-work.md`

Plus Acceptance Criteria (dedicated JIRA field, not the description) -- `.rulesync/docs/jira/ticket-sections/acceptance-criteria.md`.

## Example to mirror

`.rulesync/docs/jira/ticket-examples/standard.md` -- all six sections tight, with an outcome-based AC list.
